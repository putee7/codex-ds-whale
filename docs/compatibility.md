## 客户端更新

增强使用内部本机 IPC `query-cache-invalidate`，不是公开稳定的 Pet 扩展 API。客户端更新可能改变进程、窗口、素材加载或缓存刷新方式。

v1.1.0 不再把客户端版本写死：识别实际运行的 MSIX Codex 进程，检查唯一官方 Pet 窗口与位置、素材校验和、自己的 IPC 初始化及协议版本，然后尝试增强。版本切换期间等待并重新核对进程和窗口。IPC 通知代理可能由其他 OpenAI 客户端持有，代理存活不能替代 Codex 进程检测。

未知版本仍在 Doctor 中标为未验证；接口确实变化或检查失败时明确报错，不跳过几何/协议检查，也不修改客户端。旧 `--allow-untested` 参数保留兼容，已不负责放行版本。遇到异常先运行 `Stop.cmd`，再查看 `Doctor.cmd` 和本地错误原因。

普通安装启用当前用户的登录/每分钟自动恢复任务，直接运行唯一控制器；`Stop.cmd` 的持久暂停优先。安装/Repair 排队本地模式修复，必须完全退出客户端后才应用。`DisableRecovery.cmd` 可移除恢复任务。

26.1027.3384.0 存在本地 Pet 自动迁云逻辑。本机已核实迁移映射指向同名云端鲸鱼娘，导致本地控制器等待选择。处理方式为仅对该 Pet 使用本地迁移偏好保留本地图集，并恢复唯一安装位置；已在本机退出后应用、重开后恢复本地选择与同一控制器。未来客户端若改变此偏好格式或加载协议，需适配，不能保证仅凭版本号永久兼容。

## 常见情况

| 现象 | 操作 |
| --- | --- |
| 看不到鲸鱼娘 | 在 Codex 设置 → Mini 与虚拟宠物刷新、选择鲸鱼娘，并显示官方 Mini |
| 有宠物，没有增强 | 运行 `Start.cmd`；用 `Doctor.cmd` 检查版本和安装状态 |
| 思考时仍是普通待机 | 升级 v1.2.0；Doctor 中核对 `activity_mode`、`observed_threads` 与 `activity_error`，不要用鼠标悬停动作代替任务接入 |
| `Activity revision gap` | 控制器会取消旧状态并重取快照；持续出现时保留脱敏错误与 Codex 版本以便适配 |
| `Activity discovery unavailable` | 本地任务索引缺失、被占用或格式变化；已有窗口关注任务仍可订阅，但发现错误会保留在 Doctor 中 |
| `cloud_migration_conflict` | 当前是云端同名宠物；运行 `Repair.cmd`，完全退出 Codex，约 5 秒后再打开 |
| `pending_codex_exit` | 修复已排队，运行中的偏好尚未改；需完全退出，而非仅隐藏窗口 |
| 路径或代码摘要冲突 | 停止旧控制器，从当前安装入口启动；不要重新解压多个版本并行运行 |
| 关闭并重开 Codex 后尚未互动 | 控制器会等待选择和显示条件，再自动重连；确认 Mini 已显示且选中鲸鱼娘 |
| Windows 重启或更新后没有增强 | v1.1.0 自动恢复任务一般一分钟内启动；运行 Doctor 确认任务已注册、未主动暂停且 Mini 显示 |
| 源码 ZIP 无法离线安装 | 使用包含 Python 运行时的 Release 发布包 |
| 希望关闭方向和悬停增强 | 运行 `Stop.cmd`，保留官方 Pet 及基准呼吸 |

不要用静态母版手动覆盖控制器正在管理的素材。需要卸载时用 `Uninstall.cmd`，由安装备份决定恢复原先的同名 Pet，还是删除本项目安装的那个。

## 动画设置

注视呼吸由 WebP 容器内部动画播放，不会自动遵循 Codex 的“减少动态效果”开关。`Stop.cmd` 可关闭方向和悬停增强，官方 Pet 及基准呼吸仍保留，不会完全静止。

## 报告问题

提交 Codex 版本、Windows 版本、显示缩放、复现步骤，以及脱敏后的 `Doctor.cmd` 输出。不要上传全局状态 JSON、凭据、聊天、个人目录或完整用户配置。注明 Doctor 是否将当前版本标为已核验。
