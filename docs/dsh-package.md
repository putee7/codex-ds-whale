# Windows 安装说明

运行 `Install.cmd`，在 Codex 的「设置 → Mini 与虚拟宠物」选择本地「鲸鱼娘」。首次安装时如 Codex 正在运行，请完全退出，等约 5 秒再打开，让后台控制器应用本地宠物设置。已有鲸鱼娘的安装会升级到原来的目录。

安装包已带校验过的运行时、图集和动画。安装时不需要 Pillow、FFmpeg 或全局 Python。
